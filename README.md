# dotfiles

My personal dotfiles. Nothing fancy — just the configs I actually use day to day.

There are plenty of other tools and plugins out there, but I'm happy with the defaults for most things. These configs reflect what works for me, not necessarily what's best for everyone.

## What's included

- **Ghostty** — terminal emulator
- **tmux** — terminal multiplexer (replaced Zellij)
- **Fish** — shell
- **Neovim** — editor (LazyVim)
- **mise** — runtime/tool version manager

## tmux

Keybindings are the stock tmux ones — nothing rebound. The only additions are
keys that are free in the default bindings:

| key | does |
| --- | --- |
| `prefix` + `b` | btop in a popup |
| `prefix` + `K` | k9s in a popup (wrapper script lives outside this repo) |
| `prefix` + `R` | reload the config |
| `prefix` + `y` / `d` / `u` | Claude Code popup / hide / agent picker |

The last row comes from [tmux-claude-session-manager](https://github.com/craftzdog/tmux-claude-session-manager).
It and [tpm](https://github.com/tmux-plugins/tpm) are managed by tpm and not
committed here — clone tpm into `~/.config/tmux/plugins/tpm` and hit
`prefix` + `I` to install the rest.

`tmux.conf` also carries the settings the
[Claude Code docs](https://code.claude.com/docs/en/terminal-config#configure-tmux)
ask for — `allow-passthrough`, `extended-keys`, a short `escape-time` and
`focus-events` — so desktop notifications, the progress bar and Shift+Enter
survive the multiplexer.

## Theme

[Solarized Osaka](https://github.com/craftzdog/solarized-osaka.nvim) applied
across all tools.

The tmux statusline is a hand-adapted port rather than the file generated by the
theme's `extras/`: that one paints every segment in the same blue, so this
version gives each block its own accent from the palette and borrows the block
layout from [craftzdog's dotfiles](https://github.com/craftzdog/dotfiles/tree/master/.config/tmux)
(window name is the basename of the pane's cwd). Powerline separators need a
Nerd Font — Ghostty here runs JetBrainsMono Nerd Font.
