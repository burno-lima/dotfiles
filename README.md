# dotfiles

My personal dotfiles — just the configs I use day to day.

## What's included

- **Ghostty** — terminal
- **Zellij** — terminal multiplexer
- **Fish** — shell
- **Neovim** — editor (LazyVim)
- **mise** — tool version manager

## Zellij

Stock keybindings, plus a few floating panes in pane mode (`Ctrl` + `p`):

| key | opens |
| --- | --- |
| `g` | lazygit |
| `b` | btop |
| `K` | k9s |

## Theme

[Solarized Osaka](https://github.com/craftzdog/solarized-osaka.nvim) across all
tools. Needs a Nerd Font (I use JetBrainsMono Nerd Font).

## Usage

Feel free to use anything here, at your own risk.
