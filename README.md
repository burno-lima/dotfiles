# dotfiles

My personal dotfiles — just the configs I use day to day.

## What's included

- [**Ghostty**](https://ghostty.org) — terminal
- [**Zellij**](https://zellij.dev) — terminal multiplexer
- [**Fish**](https://fishshell.com) — shell
- [**Neovim**](https://neovim.io) — editor ([LazyVim](https://www.lazyvim.org))
- [**mise**](https://mise.jdx.dev) — tool version manager

## Zellij

Stock keybindings, plus a few floating panes in pane mode (`Ctrl` + `p`):

| key | opens |
| --- | --- |
| `g` | [lazygit](https://github.com/jesseduffield/lazygit) |
| `b` | [btop](https://github.com/aristocratos/btop) |
| `K` | [k9s](https://k9scli.io) |

## Theme

[Solarized Osaka](https://github.com/craftzdog/solarized-osaka.nvim) across all
tools. Needs a Nerd Font (I use JetBrainsMono Nerd Font).

## Usage

Feel free to use anything here, at your own risk.
